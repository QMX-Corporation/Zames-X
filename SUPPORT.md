# Product Support for Zames-X

Welcome to the QMX Corporation support guidelines for the Zames-X Game Engine ecosystem.

## 💬 Official Communication Channels
Do not open GitHub Issues for general questions, compiler setups, or customized shader syntax doubts. Use our official channels:
- **QMX Community Server (Discord):** [Join here](https://discord.gg/88hUjybuY5)

## 🛑 Before Asking
Before requesting support for rendering configurations or compiler diagnostics via `renderer.hc` or `main.hc`:
1. Verify that your HolyC execution host or TempleOS environment is properly aligned with our strict non-legacy guidelines.
2. Ensure your custom shader files (`color.ks` and `pixel.klsl`) are parsed correctly according to the globalState specification rules to prevent initialization stalls.
